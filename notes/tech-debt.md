## Unknown command-line options (P6)

- [x] **Examples refuse options they do not read (2026-10-29).** On 2026-10-25 a `froya_real_data` binary built before `site=`/`nu=` existed ran a farm sweep as plain tides: its parser looked up the keys it knew in a `HashMap` and never looked at the rest. `examples/common/arguments.rs` (`Arguments`) records every key a parser asks for, given or not, and `refuse_unread` errors on the others once the parser is done ("unknown or unused option(s): spinup_hous ..."). `froya_real_data` (with `FarmOptions::parse`), `farm_3d` and `local_time_stepping_farm` use it. The farm's keys count as read only when `site=` is given, so `farm_control=0.1` without a site is refused. Bare words are kept as flags (`wind`), so a misspelt bare flag is refused too; `farm_3d` and `local_time_stepping_farm` dropped them before. Every top-level key in the command lines recorded in `notes/`, `docs/` and `scripts/` parses (the `around=`, `dump=`, `perturb=`, `export=` there are `debug_3d=` fields). Still to port: `wave_growth`, `norkyst_boundary_tides`, `tide_gauge_fit` and `common/dap.rs`'s users (TODO P6).
